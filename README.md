# 🔎 EncontraIF

Sistema web de achados e perdidos para o IFCE.

---

## 👥 Integrante
- Rafaelly Lorena Barros dos Santos.

---

## 🎯 Objetivo
Centralizar objetos perdidos e encontrados dentro do campus.

---

## ❗ Problema
Alunos frequentemente perdem objetos no campus e não existe um sistema organizado para registrar e localizar itens.

---

## 💡 Solução
O EncontraIF permitirá que usuários publiquem itens perdidos ou encontrados, facilitando a devolução dos objetos.

---

## 🚀 Funcionalidades
- Cadastro e login
- Publicação de itens
- Upload de imagens
- Busca dinâmica
- Categorias
- Controle de status

---

## 🛠️ Tecnologias
- Django
- SQLite
- HTML
- CSS
- JavaScript
